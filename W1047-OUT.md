   for input recall, the same role and field family as the claude-code
   `~/.claude/history.jsonl`. Decision: **collect it as the machine log the

   integration suite passes untouched). With no sqlite store on this
   surface, a transcript archives on its own file-name stem, newest-mtime
   copy per duplicated id, sidecars excluded (`.ndjson` journals, render
   `.txt` caches, `tool-results/` subdirectories, unmeasured deeper
   nesting).

   recognized session without a record (the file name is the only record a

   arithmetic of `archive_gaps` turns collect PARTIAL **exit 3, never 0** —
   the transcripts-only counterpart of the store's live-row-without-
   transcript rule. There is no tombstone arm (no store to observe
   deletions). Directory-level unknowns (unlistable roots/slug dirs) keep
   the fleet-wide convention: unknown count + walk-incomplete note, which
