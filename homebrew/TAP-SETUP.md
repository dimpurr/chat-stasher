# TAP-SETUP.md — superseded

This one-time setup guide is obsolete: the tap already exists as
[`dimpurr/homebrew-tap`](https://github.com/dimpurr/homebrew-tap) (Homebrew
short name `dimpurr/tap`) — `brew install dimpurr/tap/chat-stasher`. Formula
updates arrive as draft PRs opened by `release.yml`'s `homebrew-tap` job.
The authoritative procedure is step 9 of
["Cutting a stable release"](../RELEASING.md#cutting-a-stable-release) in
RELEASING.md. The old text stays in git history.
